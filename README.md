# corridas

O objetivo deste repositório é encontrar e listar corridas de rua em Brasília-DF.

As seguintes fontes de dados são utilizadas nas buscas:
- Central da Corrida: https://centraldacorrida.com.br/
- Ticket Sports: https://www.ticketsports.com.br/
- Minhas Inscrições: https://minhasinscricoes.com.br/pt-br/calendario?url=corrida-de-rua
- Brasil que Corre: https://brasilquecorre.com/distritofederal
- Corridas Brasil: https://corridasbrasil.com.br/calendario/
- Correr Brasília: https://correrbrasilia.com.br/calendario/
- Corridas BR: https://www.corridasbr.com.br/df/calendario.asp
- Bora Correr: https://coelhodeprograma.com.br/boracorrer/
- Brasil Corrida: https://brasilcorrida.com.br/
- Portal das Corridas: https://www.portaldascorridas.com.br/
- Runner Brasil: https://www.runnerbrasil.com.br/
- LiveRun: https://www.liverun.com.br/
- TF Sports: https://www.tfsports.com.br/run-series/
- SESC DF: https://www.sescdf.com.br/corridas
- Instagram: https://www.instagram.com/corridasdistritofederal/

As seguintes informações são disponibilizadas para cada corrida:
- Imagem de capa
- Título
- Data e horário do evento
- Localização
- Distâncias
- Caso o evento ocorra em múltiplas datas de acordo com as distâncias, uma data e horário para cada distância será disponibilizada e relacionada
- Link para a página principal do evento
- Link(s) direto(s) para inscrição
- Inscrições disponíveis e respectivos valores

A lista de corridas está ordenada em ordem crescente de data do evento.
